AnisPaper

Live wallpapers for KDE Plasma 6. The heavy engine runs in another process; Plasma only shows the frame. The desktop moves without taking plasmashell down with it.

Download v0.2.0 Source code
KDE Plasma 6 Wayland Scene Engine Multi-monitor Linux

Why it exists

Dropping a Wallpaper Engine runtime inside plasmashell asks the desktop to survive broken shaders, video and Workshop packs. AnisPaper splits the work: native UI, daemon, isolated renderers, and a tiny plugin called AnisPaper Frame.

  • SceneWallpaper Engine type:scene projects, around 60 fps at 1080p when the scene allows it.
  • VideoIsolated mpv, VAAPI, a steady 30 fps per monitor.
  • Multi-monitorOne wallpaper per output. DP and HDMI stay out of each other's way.
  • WorkshopSteam library discovery, catalog and properties.

Not Electron

The UI is Qt. The daemon is native. The scene engine is a separate child.

Plasma does not render

AnisPaper Frame only reads SHM and paints it. If the renderer dies, the shell stays up.

Experimental

Living project. Scene and video are the real path. Forks and reports welcome.

Try it

Linux, KDE Plasma 6, Wayland session. Current release: v0.2.0. You can also build from the repo.

git clone https://github.com/NixaXI/AnisPaper.git
cd AnisPaper
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX="$HOME/.local"
cmake --build build -j"$(nproc)"
cmake --install build
systemctl --user daemon-reload
systemctl --user enable --now anispaper.service
