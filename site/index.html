AnisPaper

Wallpapers vivos para KDE Plasma 6. El motor pesado corre en otro proceso; Plasma solo muestra el cuadro. El escritorio se mueve sin llevarse puesto a plasmashell.

KDE Plasma 6 Wayland Scene Engine Multi-monitor Linux

Por qué existe

Meter un motor de Wallpaper Engine dentro de plasmashell es pedirle al escritorio que sobreviva a shaders, video y Workshop rotos. AnisPaper parte el trabajo: UI nativa, daemon, renderers aislados, y un plugin mínimo llamado AnisPaper Frame.

  • SceneProyectos Wallpaper Engine type:scene, a ~60 fps en 1080p cuando la escena lo permite.
  • Videompv aislado, VAAPI, 30 fps estables por monitor.
  • Multi-monitorUn wallpaper por salida. DP y HDMI no se pisan.
  • WorkshopDescubrimiento de librerías Steam, catálogo y propiedades.

No es Electron

La UI es Qt. El daemon es nativo. El scene engine es un hijo aparte.

Plasma no renderiza

AnisPaper Frame solo lee el SHM y lo pinta. Si el renderer cae, el shell sigue.

Experimental

Proyecto vivo. Scene y video son el camino real. Forks y reportes bienvenidos.

Probarlo

Linux, KDE Plasma 6, sesión Wayland. Release actual: v0.2.0. También se puede construir desde el repo.

git clone https://github.com/NixaXI/AnisPaper.git
cd AnisPaper
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX="$HOME/.local"
cmake --build build -j"$(nproc)"
cmake --install build
systemctl --user daemon-reload
systemctl --user enable --now anispaper.service
